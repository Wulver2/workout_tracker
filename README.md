# Workout_Tracker
Status: Work in progress
## Features
Current:
* Log Workouts: name, date, exercises with reps, sets, etc
* View and delete previous workouts
* View Exercises in database

Upcoming:
* Warning before deleting workouts
* Ability to edit previous workouts
* Search and filter for exercises based on equipment and muscle groups targeted
* User authentication
* Dashboard: quick view of last workout(s), display of new PR
## Built With
* Frontend: React
* Backend: Node.JS, Express
* Database: PostgreSQL
